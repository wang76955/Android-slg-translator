# Ren'Py Engine P0-1/2/3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现优化文档优先级前三项：RPA-1/2/3 归档读取、旧版整文件 zlib rpyc 回退、LocalLlmEngine 确定性占位符保护，同时保持现有 APK 功能不回退。

**Architecture:** 在原生 Java 插件侧新增 `RpaArchive` 纯工具类，负责解析 RPA 索引和按虚拟路径读取内部文件；扩展 `RpycTextExtractor.readSlot` 支持 legacy rpyc；在 `LocalLlmEngine` 翻译前后加入 sentinel 保护和还原校验。所有能力先用 Python 构造 fixture + Java harness 的失败测试驱动。

**Tech Stack:** Java 8、Capacitor 原生插件、zlib、Python unittest、Java harness（javac/java）。

## Global Constraints

- 不修改翻译文本内容、缓存 key 格式、API 参数语义。
- 不在 Android 端移植完整 Ren'Py Python 解析器/编译器。
- 不重写 RPA 实现注入；注入仍写 APK 的 `assets/x-game/x-tl/...`。
- 新测试必须从 `apk-work/ui-redesign` 目录运行。
- 每次代码改动先写失败测试，再实现。
